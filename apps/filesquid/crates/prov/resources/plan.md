# Implementation Plan: prov (`filesquid-prov`)

The `prov` module of FileSquid: W3C PROV-O history of OCFL versions and changes in the versioned JSON-LD profile `filesquid-prov/1` ([ADR 040](../../../../../resources/architecture/040-prov-o-history.md), [SRS](./srs.md)). A stand-alone module crate: default dependencies exclude every other FileSquid crate, an optional `ocfl` feature adds `filesquid-ocfl`, and no feature adds `filesquid-native` or `filesquid-c2pa`. Global sequence: [implementation-plan.md](../../../../../resources/implementation-plan.md).

Cargo commands run from `apps/filesquid/` (the product-local workspace) with `-p filesquid-prov` once PV-0.1 has created the crate and added it to the workspace members: `cargo test -p filesquid-prov --locked`, `cargo test -p filesquid-prov --features ocfl --locked`, `cargo fmt --all`, `cargo clippy -p filesquid-prov --all-targets --locked -- -D warnings`. The crate MUST build and test on its own and for `wasm32-unknown-unknown`. Allure/JUnit under `tests/allure-results/`.

## Phase F2: PROV-O history engine (global Task FS-2.8)

- [x] **Task PV-0.1: Crate, PROV-O model and profile `filesquid-prov/1`**
  - **Status:** Complete ([Walkthrough](./tasks/Task-PV-0.1-Walkthrough.md)); delivered with the PROV-O history rows of global Task FS-2.8 in PR #86, ticked afterwards.
  - **Description:** Create `apps/filesquid/crates/prov` (crate `filesquid-prov`, MIT, `#![deny(missing_docs)]`) and add it to the workspace members. Model `prov:Entity`, `prov:Activity`, `prov:Agent` (with `prov:SoftwareAgent`; no `prov:Person`) and the relations `used`, `wasGeneratedBy`, `wasDerivedFrom`, `wasInvalidatedBy`, `wasAssociatedWith`, `wasAttributedTo` and `actedOnBehalfOf`, with RFC 3339 UTC times ([PROV-S-002](./srs.md)). Serialize and parse the JSON-LD profile with its embedded context (`prov:` = `http://www.w3.org/ns/prov#`, `fsq:` = `https://filesquid.tech/ns/prov/v1#`), deterministic output, the identifier forms of PROV-S-003 and the parsing bounds of PROV-S-004 (1 MiB, depth 16, repeated keys, unknown profile; fixed error codes naming no stored value). The builder turns caller-supplied version facts into exactly one activity per committed OCFL object version (an operation that commits several objects yields one activity per object version, all sharing its operation ID; ADR 040 Decision 1) with its entities and agents, states unobserved agents as unrecorded, and models the owner as a plain `prov:Agent` identified by the caller-supplied installation UUID (no `prov:Person`, no display name). Add the in-memory history index of PROV-S-005 with pages of 1 to 1000 items. Isolation tests MUST fail if a default dependency names another FileSquid crate or if any feature names `filesquid-native` or `filesquid-c2pa`, and the crate MUST build for `wasm32-unknown-unknown`.
  - **Estimated Time:** 14 hours
