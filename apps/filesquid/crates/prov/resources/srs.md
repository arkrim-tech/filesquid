# filesquid-prov SRS (planned)

The `prov` module of FileSquid: W3C PROV-O history of OCFL versions and changes. Parent: [SRS-F-067](../../../../../resources/srs.md#srs-f-067-prov-o-history-of-every-version-and-change). Decision record: [ADR 040](../../../../../resources/architecture/040-prov-o-history.md). The crate does not exist yet; Task PV-0.1 creates it.

| Local requirement | Parent |
|---|---|
| PROV-S-001 Stand-alone module. Default dependencies MUST exclude every other FileSquid crate (including `filesquid-core`); no feature MAY add `filesquid-native` or `filesquid-c2pa`. Default dependencies MUST also exclude Axum, Tauri, SQLite, libvips and FFmpeg. The default build MUST do no filesystem or network I/O, MUST build for `wasm32-unknown-unknown` and MUST build, test and publish on its own; public items MUST have rustdoc. An optional `ocfl` feature, off by default, MAY add `filesquid-ocfl`. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [PRD TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), [T-052](../../../../../resources/product-vision.md#api-and-hosts) |
| PROV-S-002 Model. The crate MUST model `prov:Entity`, `prov:Activity`, `prov:Agent` (with `prov:SoftwareAgent`; the owner is a plain `prov:Agent` identified by an installation UUID, never a `prov:Person`) and the relations `prov:used`, `prov:wasGeneratedBy`, `prov:wasDerivedFrom`, `prov:wasInvalidatedBy`, `prov:wasAssociatedWith`, `prov:wasAttributedTo` and `prov:actedOnBehalfOf`, with `prov:startedAtTime` and `prov:endedAtTime` as RFC 3339 UTC. An entity MUST carry its OCFL object ID, version, logical path and SHA-256 digest; an activity its operation ID, operation kind and journal entry IDs; an agent an opaque identifier and, for software, a name and version. No agent carries a person identity or display name. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [SRS-F-067](../../../../../resources/srs.md#srs-f-067-prov-o-history-of-every-version-and-change) |
| PROV-S-003 Profile `filesquid-prov/1`. Records MUST be one UTF-8 JSON-LD document each, with an embedded `@context` mapping `prov:` to `http://www.w3.org/ns/prov#`, `xsd:` to `http://www.w3.org/2001/XMLSchema#` and `fsq:` to `https://filesquid.tech/ns/prov/v1#`, a `fsq:profile` value and a `@graph`. Identifiers: activity `urn:filesquid:activity:<operation-id>:<object-id>:<version>`, entity `urn:filesquid:entity:<object-id>:<version>:<percent-encoded logical path>`. Serialization MUST be deterministic (stable member and node order) so equal inputs give equal bytes. Readers MUST read every earlier profile version. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [T-058](../../../../../resources/product-vision.md#canonical-ocfl-state-and-evidence) |
| PROV-S-004 Builder and validation. A builder MUST turn caller-supplied version facts (object ID, version name, `created`, `user`, message, the logical-state diff with digests, agents, journal entry IDs) into exactly one activity with its entities and agents: an added path is generated with no derivation, a changed path is generated and derived from the state it replaces, a moved path derives from its old path, a removed path is invalidated, and an agent the caller did not observe is stated as unrecorded. A record MUST stay at or below 1 MiB: entities that do not fit go into further parts `provenance/<version>-2.jsonld`, `-3` and so on, each repeating the activity node. Parsing MUST refuse a record above 1 MiB, JSON nesting deeper than 16, repeated keys, an unknown profile and a node that breaks the profile, each with a fixed error code that names no stored value. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [SRS-F-067](../../../../../resources/srs.md#srs-f-067-prov-o-history-of-every-version-and-change) |
| PROV-S-005 History index. An in-memory index MUST answer, with bounded pages (1 to 1000 items), the activities of an object, of an entity, of an operation, of an agent and of a time range, ordered by end time then activity identifier. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change) |
| PROV-S-006 `ocfl` feature. With the feature, the crate MUST read the record `provenance/<version>.jsonld` of any version, list an object's records, produce a version-bound record for a commit through the change-model hook of OCFL-S-024, and derive backfill records from an object's inventories (`created`, `user`, message and state diff), marked `fsq:derivation` `reconstructed` with their own `fsq:recordedAt` time. It MUST NOT write outside the change model. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [PRD F-042](../../../../../resources/prd.md#f-042-ocfl-preservation-and-portable-recovery) |
| PROV-S-007 Commands. The crate MUST provide the command logic for `fsquid prov show`, `prov log`, `prov validate` and `prov export`, routed by `filesquid-cli`, and ships no binary of its own ([ADR 036](../../../../../resources/architecture/036-single-fsquid-cli.md)). | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [C-057](../../../../../resources/product-vision.md#module-rules) |
