# Implementation Plan: core (`filesquid-core`)

Portable contracts shared by every FileSquid module, host and distribution: opaque IDs, repository, library, collection, virtual collection, virtual exhibit, file, jobs, crypto envelopes and provenance records. This crate MUST NOT link Axum, Tauri, libvips, FFmpeg, or OCFL disk/S3 I/O ([TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), [CORE-S-003](./srs.md)). Global sequence: [implementation-plan.md](../../../../../resources/implementation-plan.md).

Cargo commands run from `apps/filesquid/` (the product-local workspace) with `-p filesquid-core`: `cargo test -p filesquid-core --locked`, `cargo fmt --all`, `cargo clippy -p filesquid-core --all-targets --locked -- -D warnings`. The crate MUST build and test on its own. Allure/JUnit under `tests/allure-results/`.
