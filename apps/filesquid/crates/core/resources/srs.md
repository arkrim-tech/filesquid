# Core crate SRS (scaffold)

This SRS is bounded to `filesquid-core` (portable contracts shared by every FileSquid module, host and distribution). It does not implement the full product.

| Local requirement | Parent |
|---|---|
| CORE-S-001 Newly generated identifiers for repository, library, collection, virtual collection, virtual exhibit, file, FileVersion, FileResource, and folder MUST be RFC 4122 / RFC 9562 UUID version 4, stored as lowercase 8-4-4-4-12 hexadecimal with hyphens. They MUST NOT encode a capture date or filesystem path. | [PRD F-001](../../../../../resources/prd.md#f-001-independent-local-library-and-ownership), [PRD F-049](../../../../../resources/prd.md#f-049-product-component-terminology-and-item-type), [PRD F-053](../../../../../resources/prd.md#f-053-virtual-exhibit), [PRD TC-001](../../../../../resources/prd.md#tc-001-immutable-originals-and-explicit-identity), [ADR 021](../../../../../resources/architecture/021-uuid-v4-identifiers.md) |
| CORE-S-002 The item type is **file**. Photo, Image, and Video MUST NOT be domain types. | [PRD F-049](../../../../../resources/prd.md#f-049-product-component-terminology-and-item-type) |
| CORE-S-003 This crate MUST NOT link Axum, Tauri, libvips, FFmpeg, `ffmpeg-sys`, or OCFL disk I/O. Public items MUST have rustdoc (`#![deny(missing_docs)]`). | [PRD TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), [PRD NFR-008](../../../../../resources/prd.md#nfr-008-maintainability-and-verified-engineering), [ADR 018](../../../../../resources/architecture/018-inline-docs-generators.md) |
| CORE-S-004 Versioned health status (`schema_version`, `status`, `product`) is shared by hosts. | [PRD F-037](../../../../../resources/prd.md#f-037-setup-updates-and-diagnostics) |
| CORE-S-005 Command envelopes MUST carry protocol schema version, operation/idempotency key, expected revision, and permitted scope; query envelopes MUST carry protocol schema version, permitted scope, and bounded page size (1–1000; owner decision 2026-10-17). Port errors MUST carry an error code and retryability. UI progress is never durable completion evidence. | [PRD F-038](../../../../../resources/prd.md#f-038-open-interfaces-and-product-exit), [PRD NFR-001](../../../../../resources/prd.md#nfr-001-preservation-and-transactional-integrity), [architecture 3.3](../../../../../resources/architecture.md#33-backend-architecture) |
| CORE-S-006 Job checkpoints are in-progress job state, not OCFL collection snapshots. Canonical receipts are durable completion. Default transfers ≤4, CPU-heavy workers ≤2, staging 10 GiB, reserve max(2 GiB, 5% destination), 5 attempts, 60 s backoff cap. Expired leases MUST NOT commit after replacement. | [PRD NFR-003](../../../../../resources/prd.md#nfr-003-bounded-processing-and-migration-endurance), [ADR 007](../../../../../resources/architecture/007-durable-jobs-and-interactive-performance.md) |
| CORE-S-007 Portable envelope types: AES-256-GCM (12-byte nonce, 16-byte tag), wrap wire `0x01`, HKDF-SHA-256 labels `filesquid/v1/{content,evidence,wrap,device}`, Argon2id 65536 KiB / 3 / 1 / 32-byte output / 16-byte salt. No key-storage I/O. Rewrap MUST NOT rewrite historical ciphertext in place. | [PRD F-029](../../../../../resources/prd.md#f-029-client-encryption-and-key-custody), [PRD TC-002](../../../../../resources/prd.md#tc-002-endpoint-processing-and-hosted-encryption), [ADR 009](../../../../../resources/architecture/009-cryptography-webcrypto-compatible-suite.md) |
| CORE-S-008 Resource-bound C2PA import records use SHA-256. Status is unsigned, signed, invalid, or unavailable. Unsigned is not a valid signed manifest. Signed records are immutable. Catalog-only actions MUST NOT claim a pixel change. Ephemeral cache is not permanent PROV-O history. Import MUST NOT invent capture. PROV-O sidecars are JSON-LD with RFC 3339 UTC. | [PRD F-043](../../../../../resources/prd.md#f-043-c2pa-records-and-action-disclosure), [ADR 015](../../../../../resources/architecture/015-prov-o-jsonld-and-c2pa-sdk.md) |
| CORE-S-009 Capability register rows MUST be nonempty. Status is equivalent, adapter-equivalent, limited, preservation-only, or unavailable. Preservation-only is not editable parity. Aggregate coverage MUST NOT conceal unavailable children. A mandatory capability MUST NOT be all-unsupported. | [PRD F-040](../../../../../resources/prd.md#f-040-compatibility-and-parity-register), [PRD TC-003](../../../../../resources/prd.md#tc-003-platform-and-provider-limits) |
| CORE-S-010 PROV-O history contract. The crate MUST define the FileSquid-facing PROV-O types: `OperationKind` (import, upload, copy, rename, move, hide, unhide, delete, restore, purge, metadata edit, label, revert, reinstate, snapshot, catalog organisation, repair, export, scrub, publish, backfill (owner decision 2026-10-23, verbatim: "provide and implement recommendations for owner's decisions 1-6", decision 3 (b), verbatim: "the backfill kind keeps the name `backfill`, which is ADR 040 Decision 7's term"), tombstone (the creation of an expired file's tombstone, ADR 041 Decision 11; token `tombstone`), unknown), the same names the API's covered-operation list uses, each with a stable token (catalog organisation is `catalog.organisation`; the former token `catalog`, which versions committed before the rename carry, MUST still be read as catalog organisation and MUST NOT be written); the `filesquid.operation.v1` version message (operation ID, kind, optional revision and label) with a format and a bounded parse that refuses an unreadable prefixed message rather than dropping it; `VersionRef` (OCFL object ID and version); `InstallationId` (a UUID v4 that names the installation agent, rendered `urn:uuid:<uuid>`; parsing only, no generation or storage I/O); `JournalLink` (operation ID and journal entry IDs); and `HistoryEntry` (one activity as the API and UI show it: kind, agents by opaque ID, times, version, journal link). `ProvOSidecar` MUST keep its retained/ephemeral gate (T-037) and gain the version reference, operation and journal link; `PROV_O_CONTEXT` MUST be the PROV namespace IRI `http://www.w3.org/ns/prov#` and `PROV_O_PROFILE_VERSION` 1 MUST name the profile `filesquid-prov/1`. No PROV-O graph types: those belong to `filesquid-prov`. | [PRD F-067](../../../../../resources/prd.md#f-067-prov-o-history-of-every-version-and-change), [SRS-F-067](../../../../../resources/srs.md#srs-f-067-prov-o-history-of-every-version-and-change), [ADR 040](../../../../../resources/architecture/040-prov-o-history.md) |
