# Implementation Plan: filesquid-cli

The `filesquid-cli` crate builds `fsquid`, the one FileSquid command-line tool ([ADR 036](../../../../../resources/architecture/036-single-fsquid-cli.md)). It is not a module: it routes to each module library's command runner and may depend on every module; no module depends on it. Since the owner decision of 2026-10-20 it also depends on `filesquid-api` and `filesquid-native` (default features) to journal every command (Task CLI-0.2). OCFL and C2PA register their command groups here through their own tasks ([IO-D.4](../../ocfl/resources/plan.md), [CP-0.5, CP-0.7, CP-2.1, CP-2.3](../../c2pa/resources/plan.md)). Global sequence: [implementation-plan.md](../../../../../resources/implementation-plan.md).

Cargo commands run from `apps/filesquid/` with `-p filesquid-cli` (`cargo test -p filesquid-cli --locked`).

## Phase F2: Journaled commands (global Task FS-2.9)

- [ ] **Task CLI-0.2: Journal every `fsquid` command**
  - **Status:** Added 2026-10-20 by the owner's decision (item 3, option A of the API-F2.10 conflict artifact `Task-API-F2.10-Conflict.md`, PR #97; [ADR 036](../../../../../resources/architecture/036-single-fsquid-cli.md) Decision 8); dispatched by global Task FS-2.9.
  - **Description:** Add `filesquid-api` (journal entry types and the `JournalStore` path) and `filesquid-native` with its default features (never `desktop`) as dependencies of `filesquid-cli`. Before any command runs, open `<data dir>/filesquid.sqlite` through `filesquid-native`'s SQLite journal store in WAL mode, so it can write beside a running desktop host; the data directory is `FILESQUID_DATA_DIR` when it is set and otherwise the desktop app's data directory for the platform (the directory `filesquid-desktop` uses for its identifier `tech.filesquid.desktop`). A command that cannot open the journal refuses to run, before it reads or writes anything else, with an error that names `FILESQUID_DATA_DIR`. Each command that changes state or fails writes one redacted entry: operation `cli.<module>.<command>`, outcome, error code and opaque IDs only (no path, file name, statement value or credential); a command that succeeds without changing anything writes none (the no-op rule of `logging-enforce.md`; no new exception). Any crate added to find the platform data directory is verified and pinned first. Replace the "planned" bullet for the CLI journal in the root README `## View logs` with the working behaviour and commands that were run.
  - **Estimated Time:** 6 hours
  - **Dependencies:** Task CLI-0.1, Task API-F2.10
  - **Related Requirements:** [API-S-031](../../api/resources/srs.md), [F-061](../../../../../resources/prd.md#f-061-activity-journal-and-live-health-monitoring), [SRS-F-061](../../../../../resources/srs.md#srs-f-061-activity-journal-and-live-health-monitoring), [F-050](../../../../../resources/prd.md#f-050-filesquid-platform-and-distributions), [SRS-F-050](../../../../../resources/srs.md#srs-f-050-filesquid-platform-and-distributions), [ADR 033](../../../../../resources/architecture/033-activity-journal-and-live-health-monitoring.md), [ADR 036](../../../../../resources/architecture/036-single-fsquid-cli.md)
