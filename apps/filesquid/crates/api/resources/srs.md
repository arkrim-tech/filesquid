# filesquid-api SRS (planned)

The single FileSquid API and FileSquid's application layer. Parents: [SRS-F-062](../../../../../resources/srs.md#srs-f-062-drive-style-views-sorting-selection-and-layout-preferences)–[SRS-F-065](../../../../../resources/srs.md#srs-f-065-file-version-history-and-retention) (API-S-011–014), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [SRS-F-058](../../../../../resources/srs.md#srs-f-058-white-label-distributions).

| Local requirement | Parent |
|---|---|
| API-S-001 Every FileSquid feature MUST be reachable through this one versioned API. UIs MUST NOT call modules, the filesystem or a database directly. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), FileSquid [U-16](../../../../../resources/product-vision.md#one-api-hosts-and-distributions) |
| API-S-002 The API contract MUST be versioned and owned by this crate (OpenAPI 3.1 in the repository). TypeScript types MUST be generated from it, and a test MUST fail when the contract and the generated types drift. Operations carry operation/idempotency key, expected revision, bounded page size, error code and retryability. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [T-048](../../../../../resources/product-vision.md#api-and-hosts), [CORE-S-005](../../core/resources/srs.md), [ADR 030](../../../../../resources/architecture/030-filesquid-api-and-transports.md) |
| API-S-003 The router MUST be transport-agnostic and mounted unchanged by the desktop host (custom URI scheme) and `filesquid-server` (HTTP). It MUST provide one event channel for job progress and change notifications; the transport is the outcome recorded in ADR 030. Clients MUST NOT depend on receiving every event: a subscriber that misses events MUST receive an `events.resync` hint instead of a silent gap and rereads durable state. The channel MUST be bounded: each subscriber lags at most 256 events, each event encodes to at most 65,536 bytes, and at most 64 client subscriptions are open at once (the next is refused with a retryable `unavailable` error). Every topic and its payload MUST be documented in the contract ([ADR 030](../../../../../resources/architecture/030-filesquid-api-and-transports.md) Decision 4). | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), FileSquid [U-17](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [T-049](../../../../../resources/product-vision.md#api-and-hosts), [T-050](../../../../../resources/product-vision.md#api-and-hosts) |
| API-S-004 Every call MUST be authenticated and authorised before files, SQL or keys are touched: per-launch token on desktop; accounts, groups and collection-level permissions on the server. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [F-034](../../../../../resources/prd.md#f-034-family-accounts-and-shared-libraries), FileSquid [U-06](../../../../../resources/product-vision.md#platform-ownership-and-access), [U-18](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [T-053](../../../../../resources/product-vision.md#api-and-hosts) |
| API-S-005 Responses MUST carry opaque handles, never raw filesystem paths or SQL. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), FileSquid [U-18](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 002](../../../../../resources/architecture/002-tauri2-desktop-shell.md) |
| API-S-006 Application meaning (catalog, search, replica, the FileSquid OCFL application profile) MUST be implemented here once for every host. The crate MUST NOT link Tauri host APIs, libvips, FFmpeg or a SQLite driver and MUST NOT perform storage I/O itself; hosts inject storage backends. Cargo features MUST NOT be the only boundary. | [TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), FileSquid [U-31](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 001](../../../../../resources/architecture/001-shared-rust-core-with-tauri-and-axum-hosts.md) |
| API-S-007 The API MUST read the active distribution manifest and expose enabled modules and capabilities; a disabled module MUST return an explicit unavailable error. | [F-058](../../../../../resources/prd.md#f-058-white-label-distributions), FileSquid [U-24](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [U-25](../../../../../resources/product-vision.md#one-api-hosts-and-distributions) |
| API-S-008 Every content or organisation change MUST commit an OCFL version through the `filesquid-ocfl` change model; there MUST NOT be a second write path. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [F-051](../../../../../resources/prd.md#f-051-ocfl-module), FileSquid [U-01](../../../../../resources/product-vision.md#platform-ownership-and-access), [U-03](../../../../../resources/product-vision.md#platform-ownership-and-access), [OCFL-S-016](../../ocfl/resources/srs.md) |
| API-S-009 Module and API boundaries MUST return errors the UI can show; a failed request MUST NOT crash a host. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [F-037](../../../../../resources/prd.md#f-037-setup-updates-and-diagnostics), FileSquid [U-26](../../../../../resources/product-vision.md#one-api-hosts-and-distributions) |
| API-S-010 The crate MUST build for `wasm32-unknown-unknown` with the `ocfl` and `metadata` modules for the encrypted browser host, without native processing. | [F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [SRS-F-056](../../../../../resources/srs.md#srs-f-056-single-filesquid-api), [F-036](../../../../../resources/prd.md#f-036-browser-and-mobile-web-experience), FileSquid [U-22](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [U-23](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 008](../../../../../resources/architecture/008-browser-wasm-scope.md) |
| API-S-011 The API MUST expose one paged view operation (view, sort key incl. `modified_by_me` and `opened_by_me`, direction, folder placement, view-local filter, cursor), per-user UI preferences, storage use per library and collection, copy (new FileId with source provenance), move (new OCFL version) and a streamed multi-item ZIP download of at most 1,000 members and 10 GiB with the outgoing metadata policy applied per member. | [F-062](../../../../../resources/prd.md#f-062-drive-style-views-sorting-selection-and-layout-preferences), [SRS-F-062](../../../../../resources/srs.md#srs-f-062-drive-style-views-sorting-selection-and-layout-preferences) |
| API-S-012 The API MUST expose one search operation with the published operator grammar (quotes, `-term`, `type:` with `folder` from path semantics, `in:`, `title:`, `owner:`, `creator:`, `tag:`, `is:favorite`, `is:deleted`, `is:unfiled`, `before:`, `after:`, `createdbefore:`, `createdafter:`, `source:`, `generator:`, `size>`/`size<` with byte or `KB`/`MB`/`GB` operands, and on the server `sharedwith:` (`external` not adopted), `to:`, `from:`, `pendingowner:`), permission-filtered before ranking, relevance as default order, explicit error for unknown operators, and indexes rebuildable from OCFL. | [F-063](../../../../../resources/prd.md#f-063-file-search-query-language-and-filter-chips), [SRS-F-063](../../../../../resources/srs.md#srs-f-063-file-search-query-language-and-filter-chips) |
| API-S-013 The API MUST derive the user activity stream and per-file activity from the activity journal at read time within the caller's permissions, store comments as journaled application data recoverable with the file, push `activity.entry` and `comment.update` events per subscriber, MUST NOT expose an RSS, Atom or bearer-link feed, and MUST offer the opt-in `publish-atproto` capability (connect an AT Protocol account, publish one chosen public file or readable activity entry per explicit request, disconnect; journaled; outgoing policy applied; credentials in the host's secret store; no automatic posting) per [ADR 034](../../../../../resources/architecture/034-at-protocol-publishing-connection.md). | [F-064](../../../../../resources/prd.md#f-064-file-activity-comments-and-user-activity-stream), [SRS-F-064](../../../../../resources/srs.md#srs-f-064-file-activity-comments-and-user-activity-stream), [F-061](../../../../../resources/prd.md#f-061-activity-journal-and-live-health-monitoring) |
| API-S-014 The API MUST list a file's OCFL versions with labels, serve any version with ranged reads, restore as one revert-or-reinstate operation, set labels (version `message` at commit, application data afterwards), report history size, and MUST NOT offer version deletion, expiry or thinning. | [F-065](../../../../../resources/prd.md#f-065-file-version-history-and-retention), [SRS-F-065](../../../../../resources/srs.md#srs-f-065-file-version-history-and-retention) |
