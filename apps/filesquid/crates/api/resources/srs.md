| API-S-020 Host descriptor. `GET /api/v1/host` MUST answer a `HostDescriptor` to every caller the host authenticates: its route action `host.read` MUST be granted to every accepted credential (the desktop per-launch token, the server administrator credential and every signed-in server user), not to administrators only, and the route MUST NOT be public (API-S-015). **Fields:** the descriptor MUST carry exactly `schema_version` `1`; `host_type`, one of `desktop`, `server` or `browser`; `operator_name`; and `hosted_service`, the state of encrypted backup and sync to the ciphertext-only hosted service (`*.filesquid.tech`, or a distribution's white label of it), with `enrolled`, `backup_enabled`, `sync_enabled` and `service_host`. **Host type:** each host MUST supply its own type when it builds the router (`filesquid-desktop` `desktop`, `filesquid-server` `server`, the encrypted browser host `browser`); the API MUST NOT derive it from a request (origin, scheme, user agent or any header). **Operator:** `operator_name` MUST be `null` on the desktop and browser hosts. | API-S-021 Navigation listing. `GET /api/v1/navigation` MUST list one level of the navigation tree, for a UI's tree and breadcrumb (route action `navigation.read`). **Levels:** without a `node` parameter it MUST answer the repository of the connected host (each host has exactly one). With `node` it MUST answer that node's children: a repository's libraries; a library's collections, then its virtual collections, then the folders implied by the logical paths of its unfiled files; a collection's folders implied by the logical paths of its files; a folder's subfolders within the same collection or the same unfiled files. A virtual collection MUST have no children here; its members are files, listed by the view operations (API-S-011). Files MUST NOT be listed. **Folders:** a folder exists only when a committed logical path implies it (OCFL-S-012); a folder implied only by hidden or deleted files MUST NOT be listed (the ordinary view of API-S-019), and a new empty folder that the UI holds as pending does not exist here. **Node:** each node MUST carry an opaque `node` handle of at most 512 bytes that clients MUST NOT parse and that MUST NOT contain a filesystem path, storage key, OCFL content path, SQL or token (API-S-005);
