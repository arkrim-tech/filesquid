# Desktop SRS (scaffold)

`filesquid-desktop`, the Tauri 2 host for FileSquid and its distributions. Native file access stays out of the webview. Parent: [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts).

| Local requirement | Parent |
|---|---|
| DE-S-001 The desktop serves the FileSquid API in-process through a Tauri custom URI scheme with no TCP listener (the API health route replaces `health_ping`). Any remaining Tauri command MUST be typed and explicitly authorized by a deny-by-default Tauri capability. | [PRD F-037](../../../../../resources/prd.md#f-037-setup-updates-and-diagnostics), [FE-064](../../../../../resources/product-vision.md#desktop-host-isolation) |
| DE-S-002 Capabilities are deny-by-default; no fs/shell/sql plugins at scaffold. The webview's Tauri capabilities MUST grant the main window only `core:event:allow-listen` and `core:event:allow-unlisten`; they MUST NOT grant any permission of the fs, shell, sql, dialog, http, process or opener plugins, `core:path` (which returns filesystem paths), the asset protocol, remote pages, webview labels or windows other than `main`. Filesystem and SQLite access stay in the Rust host behind the API authoriser. The host MUST declare an app ACL manifest so Tauri refuses every custom command that no capability grants, and the build MUST fail when a capability file, the effective Tauri configuration (base, platform file and CLI overlay merged; it MUST create no window other than `main`), the crate manifest, a linked non-core Tauri plugin (outside test-instrumented builds' WebDriver plugin), the app ACL file or a `#[tauri::command]` breaks this policy. | [PRD F-037](../../../../../resources/prd.md#f-037-setup-updates-and-diagnostics), [ADR 002](../../../../../resources/architecture/002-tauri2-desktop-shell.md) |
| DE-S-003 Logs are stdout JSON. | [PRD NFR-009](../../../../../resources/prd.md#nfr-009-observability-and-capacity-economics), [SRS-NFR-009](../../../../../resources/srs.md#srs-nfr-009-observability-and-capacity-economics), [PRD F-061](../../../../../resources/prd.md#f-061-activity-journal-and-live-health-monitoring), [ADR 014](../../../../../resources/architecture/014-stdout-observability.md) |
| DE-S-004 Desktop links `filesquid-api`, which links `filesquid_ocfl` and `filesquid_metadata`, and `filesquid_c2pa` only in builds that include the `c2pa` module (no MVP or release-1 build does, [ADR 037](../../../../../resources/architecture/037-c2pa-in-release-2.md)), and injects the local filesystem and S3-compatible storage backends; the F5 browser host links the same crates; the ciphertext-only hosted service MUST NOT ([ADR 025](../../../../../resources/architecture/025-client-side-filesquid-engines.md), [ADR 032](../../../../../resources/architecture/032-hosting-and-privacy-model.md)). | [PRD TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer) |
| DE-S-005 Every API request through the scheme MUST carry a per-launch token, except the public liveness probe `GET /api/v1/health/live` (API-S-015) and the content route `/api/v1/content/<handle>`, whose only credential is a content handle minted with that token ([API-S-018](../../api/resources/srs.md), [ADR 030](../../../../../resources/architecture/030-filesquid-api-and-transports.md) Decision 5). The scheme MUST pass content-route requests to the router and its answers, headers included, back to the webview unchanged; it MUST NOT record a content-route address except as the template `/api/v1/content/{handle}`; and a content handle MUST NOT survive a relaunch. The event channel MUST sit behind the same client interface as the server's. The event channel MUST use one counted event-bus subscription, forward its resync hints, and reach only the app's own webviews (navigation to any other origin is refused; only the blank documents `about:blank` and `about:srcdoc` are also allowed). A satisfiable `Range` request MUST pass through the scheme with its `206` status and `Content-Range`; an unsatisfiable one MUST keep its `416` status and `Content-Range: bytes */<length>`. The handler MUST buffer at most 16 MiB of one response, answering a larger one with a typed `internal` error. | [PRD F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [PRD F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [FileSquid U-18](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [T-049](../../../../../resources/product-vision.md#api-and-hosts), [ADR 030](../../../../../resources/architecture/030-filesquid-api-and-transports.md) |
| DE-S-006 The webview MUST receive opaque handles and API responses, never raw filesystem paths or SQL. | [PRD F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [PRD F-056](../../../../../resources/prd.md#f-056-single-filesquid-api), [FileSquid U-18](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 002](../../../../../resources/architecture/002-tauri2-desktop-shell.md) |
| DE-S-007 One desktop binary MUST serve every distribution through a Tauri config overlay (product name, identifier, icons, UI directory). | [F-058](../../../../../resources/prd.md#f-058-white-label-distributions), [FileSquid U-34](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 029](../../../../../resources/architecture/029-filesquid-unified-product-and-distributions.md) |
| DE-S-008 Desktop import MUST gather every file-record fact the host operating system provides for each source file before its OCFL commit (on macOS: file size in bytes; birth, modified, status-changed, accessed and date-added times; owner, group, mode, ACL and BSD flags; symbolic link or alias target; UTI; every extended attribute, including `com.apple.quarantine`, `kMDItemWhereFroms` and Finder tags; volume name, UUID and filesystem type; OS version and build, host name and account) and pass them to the `metadata` module's file record; facts it cannot read are passed as unavailable with a reason ([ADR 038](../../../../../resources/architecture/038-import-file-record.md)). | [PRD F-002](../../../../../resources/prd.md#f-002-safe-file-folder-and-device-import), [SRS-F-002](../../../../../resources/srs.md#srs-f-002-safe-file-folder-and-device-import) |
