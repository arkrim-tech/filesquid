# Implementation Plan: ui (`@filesquid/ui`)

`@filesquid/ui` is FileSquid's default distribution and the component library every distribution builds on: the `FileSquidClient` API client and host adapter, standard custom elements written in vanilla TypeScript (`<fs-app-shell>`, `<fs-file-browser>`, `<fs-metadata-panel>`, `<fs-credentials-panel>`, …), the token and label-table contract, and the Drive-style default app ([ADR 031](../../../../resources/architecture/031-vanilla-typescript-ui-and-white-label-theming.md)). Components are styled only through design tokens and worded only through the label table keyed by internal names (repository, library, collection, virtual collection, virtual exhibit, file). The UI calls the FileSquid API and nothing else; it contains no Rust and no server code. ImageSquid and later Arkrim consume this package by path during development and by published version for release.

Rows marked "Moved" come from the former `apps/frontend` plan (generic shell, host adapter, tokens, file management and protection UI) and were renumbered from `FE-x.y` to `UI-x.y` on 2026-10-16 so the task prefix no longer collides with the vision's `FE-###` feature requirements; photo views stayed in ImageSquid (`IS-x.y`). Every row uses the `UI` prefix. Module SRS: [srs.md](./srs.md).

Commands run inside `apps/filesquid/ui/` (Vite dev `127.0.0.1:5173`, preview `4173`): `npm ci`, `npx prettier --check .`, `npx eslint .`, `npm run check`, `npm test`, `npm run build`, `npm run test:e2e`. UI tests: Playwright against `vite build` plus `vite preview`, strict DOM assertions, no console errors ([UI-S-013](./srs.md), [ADR 017](../../../../resources/architecture/017-test-runners-and-reporting.md)). Allure under `tests/allure-results/`, cleared in `pretest`. Gherkin under [`tests/features/`](../tests/features/). Global sequence: [implementation-plan.md](../../../../resources/implementation-plan.md).

**Holistic UI:** implement the shell, browser, panels and theme so later requirements (ImageSquid views, the browser host, Arkrim) extend the same interaction model. Do not ship a throwaway shell.
