Crates, hosts and the privacy graph

Crates are the unit of privacy. Three hosts mount the same filesquid-api router, and the router depends on module crates that never depend on each other by default. The hosted service is a separate binary whose dependency graph cannot contain private-content crates.

One upload, from click to commit

The borrow checker's rules reappear as runtime protocol. A job holds an exclusive lease like a &mut borrow, the OCFL commit is a chain of states that each consume the last, and a dropped guard cleans up after any error.

Toolchain, from source to four artefacts

Every quality gate is a Cargo command run by the local pre-commit hook. The graph gate is what turns the hosted-service rule above into a build failure.
