Why

Leave any service and keep the whole story

Cloud drives hand back the bytes when you leave, not the versions, descriptions and sharing history. Archives keep that context, but they are built for institutions. FileSquid brings archival discipline to everyday files, without asking you to become an archivist or a system administrator.

Local-first and offline

Your library lives on your machine and works without a connection. Optional hosting and sync add convenience, never dependence.

Full ownership

Originals, edits, dates, descriptions, organisation and relationships stay together, so your files keep their meaning.

Portable by design

Move between providers, recover from mistakes, or stop using FileSquid altogether, without losing originals or the work you added.

Traceable provenance

Every import starts a PROV-O audit trail of who did what, so files can show where they came from, including whether AI was involved.

Your AI, your choice

Connect a local model or your own provider account. You pick the model per task and pay the provider directly; backup never sees inference traffic.

Fast at any size

Browsing, previews and search stay responsive in large libraries while imports, indexing and provenance scans run in the background.

How it works

A familiar drive on top, an archive underneath

Folders, previews, a details sidebar, version history and sharing, like the cloud drives you know. Underneath, every file is stored the way archives store them, so the collection stays readable with ordinary file tools and can be rebuilt from disk if the app's indexes are ever lost.

OCFL storageVersioned files and inventories in the Oxford Common File Layout, the archives' standard for keeping files on disk.
Dublin Core metadataDescriptions in an ISO standard vocabulary, alongside the native EXIF and file facts.
PROV-OMachine-readable history of every file and metadata change.
Any hostDesktop app on Windows, macOS and Linux, a server you run, or an encrypted browser host.
